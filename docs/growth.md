# 몇프로 — 첫 화면·공유 루프 설계 (2026-11-20)

## 왜 바꿨나

관리자 대시보드 수치(2026-08-10 ~ 11-20):

- 방문자 4,571명 중 유입의 81%가 메타 광고(인스타 2,863 + 페이스북 1,536), 검색 유입은 8건.
- 광고를 끈 10월 30일 이후 하루 방문자는 1~2명.
- 측정을 해본 사람 75명(1.6%), 가입 5명, 다시 로그인한 사람 0명.
- 측정 168건 중 14건은 입력란 예시 문구 그대로, 투표 59건 중 45건은 운영자 본인.

광고는 사람을 데려왔지만 들어온 사람이 쓰지도, 돌아오지도, 남에게 보여주지도 않았다.
광고를 다시 켜기 전에 이 세 가지를 고친다.

## 바꾼 것

### 첫 화면
- **예시 칩**: 무엇을 물어볼지 모르는 사람이 한 번 눌러 시작한다. 14개 중 무작위(모바일 3개, 그 외 5개).
  연애·친구·학교·직장·경조사·이웃이 섞여 있다(실제 이용자는 10~20대가 많았다).
- **빈 입력으로는 측정하지 않는다.** 예전에는 예시 문구로 대신 측정해서 같은 사연이 쌓였다.
- **오늘의 논쟁 미리보기**: 제목을 누르면 공감률이 열린다. 1분을 기다리지 않아도 서비스가 뭘 하는지 보인다.
- **다른 사람들이 재본 생각**: 최근 측정 5건. 누르면 그 결과의 공유 페이지로 간다.
- **대기 중 볼거리**: 측정이 도는 동안 다른 논쟁·측정의 공감률을 한 줄씩 보여준다.

### 공유 (`share.py`)
- `/r/{id}` 결과 공유 페이지, `/og/{id}.png` 카드 이미지(1200x630, 서버에서 그림).
- 결과 등급 라벨(`국민 정서 그 자체` ~ `혼자만의 세계`) — 숫자만으로는 대화 소재가 안 된다.
- **친구 투표**: 링크를 받은 사람이 가입 없이 공감/비공감을 누르면 "AI 예측 vs 실제 투표"를 보여준다.
  받은 사람이 1분짜리 측정을 하지 않아도 한 번의 탭으로 참여하게 하는 것이 목적이다.
- 공개 범위는 히스토리에 이미 저장되던 "사연 앞 100자 + 결과"뿐이다. 공유 페이지는 `noindex`.

### 공개 적합성
- 예측 스키마에 `sensitive`(불특정 다수 공개 부적절 여부)를 추가했다. true면 공유 주소를 만들지 않고
  히스토리·피드에도 내보내지 않는다. 그 전에 쌓인 기록은 어휘 목록(`share._SENSITIVE`)으로 걸러낸다.
- 범죄 행위의 정당성을 묻는 사연은 성별·관계와 무관하게 한 자릿수로 추정하도록 예측 프롬프트를 고쳤다
  (2026-08-23 "74% 글쓴이 편 우세" 사고).

### 오늘의 논쟁
- 506건 중 139건(27%)이 축의금이었다. 생성 프롬프트에 영역 분산, 같은 소재 하루 1건,
  최근 7일 제목과 쟁점 중복 금지를 넣었다.
- 제목이 깨지고 요약이 빈 항목이 저장된 날이 6일 있었다. 저장 전에 검증하고(`seo.valid_item`),
  유효 항목이 3건 미만이면 저장하지 않고 재시도한다. 이미 저장된 손상 항목은 조회·색인에서 제외한다.

## 측정 방법

`/api/track`에 단계 이벤트를 추가했다(내용은 담지 않는다). `/admin`의 "이용 단계" 표에서 본다.

| 이벤트 | 뜻 |
|---|---|
| `view` | 첫 화면 방문 (`meta=share`면 공유 페이지에서 넘어온 방문) |
| `teaser` | 첫 화면에서 논쟁 공감률을 열어봄 |
| `chip` | 예시 칩으로 시작 |
| `ask` → `questions` → `predict` | 측정 시작 → 질문 도착 → 결과 확인 |
| `share` | 공유 버튼 (`meta`: native / copy / image) |
| `share_view` → `share_vote` → `share_cta` | 공유 페이지 방문 → 투표 → 내 사연 재보기 |

볼 숫자:
- `ask ÷ view` — 첫 화면 전환율. 개편 전 1.6%.
- `predict ÷ ask` — 대기 중 이탈. 낮으면 속도가 문제다.
- `share ÷ predict`, `share_view ÷ share` — 공유 한 번이 몇 명을 데려오는가.
- `share_cta ÷ share_view` — 공유로 온 사람이 자기 측정으로 넘어가는 비율.

`(share ÷ predict) × (share_view ÷ share) × (share_cta ÷ share_view)`가 대략의 전파 계수다.
0.5면 광고로 데려온 100명이 200명 효과를 낸다. 광고는 이 값을 확인한 뒤에 다시 켠다.

## 남은 결정 (운영자 판단 필요)

- **약관·개인정보처리방침**: 공유 링크와 친구 투표(IP 해시 저장)를 명시하는 문장을 넣을지.

- **카카오톡 공유 버튼**: 카카오 개발자 앱 키가 있어야 한다. 지금은 기기 공유창과 링크 복사로 대신한다.
